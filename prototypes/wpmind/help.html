常见问题与部署说明

·

官方算力与自有 API Key 可以同时启用吗？

可以。启用后两者会一起参与智能路由，并可在「智能路由」页固定优先顺序。

·

如何通过 wp-config.php 锁定服务商密钥？

定义 WPMIND_LOCKED_PROVIDERS 与 WPMIND_API_KEYS 常量后，对应服务商密钥由配置文件托管且后台隐藏输入框。

·

如何排查某项服务熔断或连接失败？

在「AI 服务」页展开对应端点点击「测试连接」，或到「工具」页导出脱敏诊断包提交支持。
