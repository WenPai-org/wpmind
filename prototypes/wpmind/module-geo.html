Schema.org

自动输出 Article、Breadcrumb 与 WebSite JSON-LD。

已开启未开启

为文章与页面注入语义结构化数据。

JSON-LD 预览

json
{
    "@context": "https://schema.org",
    "@type": "BlogPosting",
    "headline": "示例文章标题",
    "author": {
        "@type": "Person",
        "name": "Author"
    },
    "datePublished": "2026-11-21T18:00:00+00:00",
    "publisher": {
        "@type": "Organization",
        "name": "示例技术博客",
        "url": "https://example.com"
    },
    "inLanguage": "zh_CN"
}
json
{
    "@context": "https://schema.org",
    "@type": "BreadcrumbList",
    "itemListElement": [
        {
            "@type": "ListItem",
            "position": 1,
            "name": "示例技术博客",
            "item": "https://example.com/"
        },
        {
            "@type": "ListItem",
            "position": 2,
            "name": "示例文章标题"
        }
    ]
}
json
{
    "@context": "https://schema.org",
    "@type": "WebSite",
    "name": "示例技术博客",
    "url": "https://example.com/",
    "potentialAction": {
        "@type": "SearchAction",
        "target": "https://example.com/?s={search_term_string}",
        "query-input": "required name=search_term_string"
    }
}

Schema.org 说明

  • 01自动兼容 Yoast、Rank Math 与 Slim SEO。
  • 02中文字数与英文词数混合精确统计。
  • 03品牌实体开启后自动丰富 publisher。
