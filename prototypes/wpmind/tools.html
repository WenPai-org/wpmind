工具

导出诊断包与迁移端点配置。

诊断包

导出脱敏环境、模块与用量快照，不含密钥与指纹。

排查连接或模块异常时附上诊断包更快定位。

导出端点配置

下载端点与模块配置 JSON（不含密钥），用于迁移备份。

导出文件仅包含结构配置，不会泄露 API Key。

导入端点配置

先校验差异再确认写入，自动保留本站已保存的密钥。

拖入 JSON 文件，或点击选择

选择 JSON 后先预检差异，确认后写入。

两步确认机制防止误覆盖现有端点设置。
