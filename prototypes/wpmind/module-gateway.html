接入文档

OpenAI 兼容接口地址与调用示例。

Base URL

text
https://example.com/wp-json/mind/v1

可用端点

方法 路径 说明
POST/chat/completions对话补全（兼容 OpenAI）
GET/models列出可用模型
POST/embeddings文本向量化
POST/responsesResponses 接口（兼容 OpenAI）
GET/status网关健康状态

curl 调用示例

bash
curl https://example.com/wp-json/mind/v1/chat/completions \
  -H "Authorization: Bearer sk_mind_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "Hello"}],
    "stream": true
  }'

认证方式：请求头携带 Authorization: Bearer sk_mind_YOUR_KEY。
